## 📖 About

**CoreLife** is a multi-site personal brand platform created by **Lakshya Singh**. A single home page connects a professional career profile with three content brands, a shared collaboration form and a support page. Every site has its own colour identity, while sharing a consistent layout, theme system and navigation.

## ✨ Features

### 🌍 Across the whole project
- 🌗 **Light and dark themes** with a one-click toggle on every page
- 📱 **Fully responsive** from small phones to large desktops
- 🧭 **Shared navigation menu** linking every site
- 🎡 **Quarter-circle fan menu** on the header logo to jump between sites
- ✨ **Smooth animations** that stay light on performance
- 🖼️ **Local image assets** with no dependency on external image hosting

### 🏠 Home
- Hero About section with photo, tagline and call-to-action
- Profile banner cards linking to each brand site
- Collaboration and Support shortcuts

### 💼 Career
- Multi-section professional profile
- Animated mesh-gradient background
- Scroll-reveal animations and circular portrait logo

### 🎮 The Gaminggram
- Glassy blur mesh design
- Card spotlight effects and Ken Burns banner zoom
- Gaming profiles and community support section

### 💻 Bit Sa Gyan
- Tech-focused design with the Space Grotesk typeface
- Electric blue, violet and crimson-pink palette
- Social links grid and collaboration section

### 🎨 Crazy Akshat
- Navy, gold and crimson identity with a script wordmark
- Social connections grid, contact, collaboration and support sections
- Equal-height two-column desktop layout and centered mobile layout

### 🤝 Collaboration Form
- One shared form used by all sites
- Server-side handling for reliable delivery

### 💖 Support
- Multiple ways to support the projects
- Backend-verified payment flow

## 🧩 Key Files

| File / Folder | Purpose |
|---|---|
| `index.html` | Entry page that links all sites |
| `index_style.css` | Styling for the home page |
| `index_function.js` | Interactions for the home page |
| `theme.js` | Light and dark theme logic shared by pages |
| `backend/app.py` | Backend application for the form and payments |
| `backend/worker.py` | Entry point for the Cloudflare Python Worker |
| `wrangler.jsonc` | Cloudflare deployment configuration |
| `media/` | Banners, logos and other images |
